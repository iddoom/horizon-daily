## [顶尖 AI 初创公司几乎不再发表研究成果](https://www.science.org/content/article/ai-s-top-startups-are-barely-publishing-their-research) ⭐️ 7.0/10

一项最新分析显示，领先的 AI 初创公司正在大幅减少学术发表，以保护知识产权并在与更大竞争对手的较量中保持竞争优势。数据显示了一种明显背离开放科学的转变，许多公司选择保密而非传统的学术发表模式。 这一趋势代表了 AI 生态系统中的根本性转变，历史上推动进步的开放思想交流正被专有护城河所取代。较小的公司担心发表研究会让 OpenAI 和 Anthropic 等巨头复制他们的工作，这可能扼杀创新并降低整个领域的科学严谨性。 该分析使用累计引用量作为研究重要性的代理指标，其中 OpenAI 位居榜首，紧随其后的是 MEGVII、Hugging Face、Waymo 和 Anthropic 等公司。值得注意的是，研究发现许多初创公司不仅避免发表应用性成果，还避免发表基础研究，而'博客化'的兴起使得未经证实的声明在没有传统同行评审的情况下大量传播。

hackernews · YeGoblynQueenne · 7月29日 21:25 · [社区讨论](https://news.ycombinator.com/item?id=49103285)

**背景**: 从历史上看，AI 研究深深扎根于开放的学术文化，在 NeurIPS 和 ICML 等同行评审会议上发表是建立信誉和推进该领域的主要方式。然而，随着 AI 变得具有巨大的商业价值，开放科学与竞争优势之间的紧张关系不断加剧。大型科技公司和资金充足的初创公司现在拥有的计算资源远超学术机构，创造了一种被发表的研究可以被竞争对手快速产业化的环境。这导致了观察者所称的 AI 研究'博客化'，即公司发布精心制作的营销文章，而非严谨、可复现的科学论文。

**社区讨论**: 社区成员分享了在发表与竞争力之间摩擦的第一手经验，一位创始人描述了他们的初创公司如何避免一切发表，以防止 OpenAI 和 Anthropic 复制他们的工作。其他人则对科学严谨性的下降表示担忧，指出研究的'博客化'使未经证实的声明通过社交媒体动态传播，形成恶性循环，低质量输出甚至污染了训练数据。一位评论者指出，原始论文的数据显示 OpenAI 实际上在累计引用量方面领先，表明实际情况比标题暗示的更为微妙。

## [月之暗面推出半价 Kimi K3-256k API 套餐](https://www.kimi.com/code/docs/en/kimi-code/models) ⭐️ 6.0/10

月之暗面推出了全新的 Kimi K3-256k API 套餐，通过针对 256k token 以下上下文优化定价，将用户的计算配额成本降低了一半。模型本身没有变化，但消耗 256k token 或更少的用户现在只需消耗标准 K3 模型（具有 1M token 上下文窗口）约一半的配额。 这项定价更新使得大多数不需要完整 1M token 窗口的使用场景能够以大幅降低的成本进行长上下文推理。它反映了基于上下文长度进行分层定价的更广泛行业趋势，将较短上下文带来的计算节省直接传递给开发者和最终用户。 K3-256k 套餐纯粹是 API 层面的定价变更；底层模型没有进行量化或修改，在 256k 上下文限制内提供完全相同的结果。该实现采用在 256k (2^18) token 边界处的硬性截断，而非基于实际上下文使用量的平滑定价梯度。

hackernews · monneyboi · 7月29日 19:25 · [社区讨论](https://news.ycombinator.com/item?id=49101852)

**背景**: 像 Kimi K3 这样的大语言模型支持极长的上下文窗口（最多可达 100 万 token），但处理长上下文在 FLOPs 和每生成一个 token 的内存带宽方面会产生显著更高的计算成本。随着活跃上下文的增长，模型在输出每个 token 时必须从内存中读取更多数据，从而增加了实际的每 token 成本。包括 OpenAI 和 Google 在内的多家 AI 提供商已经引入了分层定价结构，一旦用户超过特定的上下文长度阈值就会收取更高费用，将这些基础设施成本转嫁给用户。
