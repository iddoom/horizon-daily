## [科学家利用 CRISPR 技术首次从雄性小鼠培育出雌性克隆体](https://www.technologyreview.com/2026/08/12/1141768/scientists-just-created-female-clones-of-male-mice/) ⭐️ 9.0/10

日本的一个研究团队成功利用基于 CRISPR 的方法，从雄性小鼠细胞中移除了 Y 染色体，首次培育出了雄性小鼠的雌性克隆体。这是科学家首次在染色体水平上故意将雄性胚胎转化为雌性。 这一突破展示了 CRISPR 技术在染色体工程中的强大新应用，代表了生殖遗传学领域的重大范式转变。它可能对物种保护、家畜育种以及我们对性别决定生物学的基本理解产生深远影响。 该技术专门针对并消除 Y 染色体，同时保持 X 染色体完整，有效地将雄性（XY）细胞重新编程为雌性（XX）配置。正如夏威夷大学的生殖生物学家 Monika Ward 所指出的，这一具体成就以前从未被实现过。

rss · MIT Technology Review · 8月12日 18:59

**背景**: CRISPR-Cas9 是一种源自细菌抗病毒防御系统的革命性基因编辑工具，允许科学家在生物体的目标位置对 DNA 进行精确修改。在哺乳动物中，生物性别由性染色体决定：雌性通常有两条 X 染色体（XX），而雄性有一条 X 染色体和一条 Y 染色体（XY）。Y 染色体包含对雄性发育至关重要的基因，将其移除理论上只会留下 X 染色体，可能允许细胞沿雌性路径发育。先前的研究表明，Y 染色体在数百万年的进化过程中一直在逐渐丢失基因，尽管它仍在雄性生育和发育中发挥着关键作用。

## [DeepSeek V4 Pro 0813 在 OpenRouter 上发布](https://simonwillison.net/2026/Aug/12/deepseek-v4-pro-0813/) ⭐️ 7.0/10

DeepSeek 悄然发布了其最新模型 DeepSeek V4 Pro 0813，目前该模型仅能通过 OpenRouter 平台的 API 进行访问。Simon Willison 观察到，根据推理级别设置为低、中或高，该模型在生成 SVG 图像时表现出了令人惊讶的显著行为差异。 此次发布标志着 AI 行业最具影响力和竞争力的实验室之一推出了一款重要的大型语言模型。基于推理级别的显著输出差异可能预示着内部思维链处理直接影响创意生成的新方式，开发者在应用时需要考虑到这一点。 该模型目前仅支持 API 调用，尽管 DeepSeek 尚未正式宣布此版本的开源权重，但鉴于此前四月份的 V4 Pro 和七月份的 V4 Flash 都已开放权重，此次开源的可能性极高。官方基准测试数据目前仍未经正式证实，这些数据最初在微信群中分享，随后在 Reddit 帖子被删除后，以 ASCII 艺术的形式被转载到了 Hacker News 上。

rss · Simon Willison · 8月12日 23:59

**背景**: DeepSeek 是一家著名的 AI 实验室，以发布能够与顶级专有模型直接竞争的高能力开源权重大型语言模型而闻名。OpenRouter 则是一个统一的 API 网关，允许开发者在不管理多个独立账户的情况下，访问来自 70 多家提供商的数百种不同的 AI 模型。像 DeepSeek 这样的现代推理模型支持“思考模式”，即在输出最终答案之前利用思维链处理来提高准确性，这通常可以通过推理努力级别等参数进行调整。
